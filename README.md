## Локальное приложение для системы Битрикс24

Учебный проект - локальное iframe django приложение интегрированное в систему Битрикс24 (с помощью api битрикса и подмодуля integration_utils для работы с этим api).

Состоит из 5 приложений, каждое из которых взаимодействует с порталом Битрикс и предоставляет определённую информацию из портала и возможности взаимодействия с порталом для конкретного пользователя.

## Функционал
На главном экране реализовано приветствие вошедшего пользователя и доступ к 5 приложениям
