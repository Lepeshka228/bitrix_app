## Локальное приложение для системы Битрикс24

Учебный проект - локальное iframe django приложение интегрированное в систему Битрикс24 (с помощью api битрикса и подмодуля integration_utils для работы с этим api).

Состоит из 5 приложений, каждое из которых взаимодействует с порталом Битрикс и предоставляет определённую информацию из портала и возможности взаимодействия с порталом для конкретного пользователя.

## Стек
- python 3.10, django4.2
- api bitrix - integration_utils
- api яндекс карт - js, геокодер
- postgresql

## В планах
Большая часть всей логики (особенно при работе с api битрикс в services.py) реализована процедурно, что не является эффективным решением (как с точки зрения структуры, так и времени выполнения, поскольку вызов всех api методов выполняется каждый раз при вызове эндпоинта);
- Реализовать более объектно-ориентированный подход - добавить датакласс с кэшированием
- Поработать над эндпоинтами - разделить загрузку, обработку и вывод информации на разные эндпоинты для лучшей расширяемости и обработки ошибок и устранения дублирования логики

### Приложение 4 - Вывод компаний на карте.
В данном приложении осуществляется работа с сущностью компании (её адресом) и api яндекс карт (на frontend стороне), для вывода местоположения зарегистрированных в системе компаний на карте.

Присутствует ссылка на внешнюю страницу (другой сервер) с той-же информацией о компаниях на карте (в случае возникновения проблем с интеграцией яндекс карт в битрикс).

### Приложение 5 - Импорт и экспорт контактов.
В данном приложении осуществляется работа с файлами, содержащими данные о контактах (csv, xlsx) и сущностями контактов и компаний.

Пользователь может загрузить свой файл с контактами в нужном ему формате и эти контакты будут добавлены в систему Битрикс к указанной компании (если указанной компании не существует в системе, будет предложено её создать).
